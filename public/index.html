        NoSQL Functionality 3
        
Indexing

        
Output of db.laps.getIndexes(): the default _id index, a compound index on { driverId, lapNumber } and a text index on circuit, plus an explain() proving the compound index is used.

      

      

      

    


    
    

      

        NoSQL Functionality 4
        
Schema Validation

        
The laps collection has a $jsonSchema validator requiring driverId, lapNumber, lapTime and telemetry. This inserts { circuit: "Monza", lapNumber: "three" } and shows the error MongoDB throws.

      

      

      

    


    
    

      

        NoSQL Functionality 5
        
Embedded Documents & Referencing

        
One full lap document as raw JSON. The telemetry object is embedded inside the lap; driverId is a reference to a document in the drivers collection.
